# Retail Data Engineering Project - V2



## Overview



This project is a hands-on retail data engineering project built from scratch using Databricks, PySpark, and Delta Lake.



The goal is to develop a reliable data pipeline that transforms raw retail data into clean, validated, and analytics-ready datasets.



## Project Objectives



- Ingest raw retail source data.

- Apply data cleaning and validation using PySpark.

- Implement the Medallion Architecture.

- Build analytics-ready fact and dimension tables.

- Process incremental data safely.

- Implement data quality checks and pipeline monitoring.

- Track project changes using Git and GitHub.



## Technology Stack



- Python

- PySpark

- Azure Databricks Free Edition

- Delta Lake

- SQL

- Git and GitHub



## Architecture



### Bronze Layer

Stores raw source data with minimal transformations.



### Silver Layer

Cleans, standardizes, and validates data.



### Gold Layer

Contains business-ready datasets for reporting and analytics.



## Project Structure



- `data/raw/` - Local raw source data
- `src/` - Source code and pipeline scripts
- `docs/` - Project documentation
- `tests/` - Data quality and testing code



## Development Approach



The project will be developed incrementally, with each pipeline component implemented and tested separately.
